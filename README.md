# 王海与李彤 · 赴一场幸福之约

这是独立的新项目，未覆盖旧项目。无需 Node 构建即可部署，`dist/` 是完整网站。照片、音乐、脚本和样式均为本地资源；地图仅在用户点击导航时打开高德。

## 内容与交互

10 张新照片全部使用：主图、大厅合照、相拥合照、新娘为主合照、新郎单人、新娘单人、外景合照、比心合照、中式合照、挥手合照。照片不美化、不修脸；缩略图仅缩放和压缩，点开查看上传原片。横图、竖图按原始比例完整呈现；文字放在照片之外。单人照独立排版，不再把比例不同的两张照片强制并列。

封面加载主图；点击开启后，由 IntersectionObserver 在模块靠近可视区域时加载该模块的照片，文字和照片依次淡入。图片有占位、加载动画和点击失败重试。支持减少动态效果的系统偏好；较旧浏览器采用一次加载的兼容路径。

BGM 为陆虎《拉过勾的》。页面打开即预加载，点击开启请柬时播放，循环并可暂停。微信/手机对有声自动播放有各自限制，入口点击能提供播放所需的用户交互。已移除分享功能。

## 本地预览

```bash
python3 -m http.server 8080 --directory dist
```

浏览器访问 `http://localhost:8080`。不要只用文件管理器打开 HTML；建议通过本地 HTTP 服务检查资源与交互。

## 大陆服务器：已有 Nginx

将 `dist/` 内的全部文件上传到服务器网站目录，例如 `/var/www/wedding-new/`。确保图片、音频的子目录结构保持不变。域名/IP 所对应站点的 root 指向这个目录。

使用提供的 `nginx.conf` 作为站点配置参考：把 `root /usr/share/nginx/html;` 改为实际目录；把 `server_name _;` 改为实际域名（没有域名时先在独立端口做预览）。不要直接替换已有网站配置。修改后先执行 `nginx -t`，检查通过再 reload。

页面 HTML 和 JS/CSS 使用 no-cache，图片/音乐缓存一小时。Nginx 原生支持 MP3 Range 请求，便于音频缓冲。可使用你现有的 HTTPS 反向代理或证书配置。

## 大陆服务器：Docker

在已有 Docker Compose 的服务器中，将整个项目目录上传，然后在该目录执行：

```bash
docker compose up -d --build
```

默认发布到 `http://服务器IP:8080`。端口可以在 `compose.yaml` 中调整。域名 HTTPS 可由你现有的 Nginx/面板转发到 8080。

## 对象存储或静态托管

把 `dist/` 内容完整上传到支持静态网站托管的平台。以 `index.html` 为入口，保留所有目录结构。所有内部路径都是相对路径，也支持部署到域名子目录。建议使用大陆区域的存储源站及同区域 CDN，照片与音乐不要继续引用 GitHub Pages。实际公网域名与 HTTPS 接入取决于你的平台和现有配置。

## 更新

更换图片、音乐后同步对应资产；部署前调整 HTML 的 CSS/JS `?v=` 版本，必要时刷新 CDN 缓存。原片仅在点开照片时下载。WebP 优先，JPEG 为兼容回退；两种都需要上传。

可选重新生成预览图：安装 Pillow 后运行 `python3 build.py`。脚本默认使用 `dist/assets/images/*-original.jpg`。如从原始中文文件名重新导入，可指定环境变量 `PHOTO_SOURCE` 为照片目录。文案与顺序在 `build.py` 中维护。运行 build.py 后保留 `style.css`、`app.js`、音乐和日历文件。
